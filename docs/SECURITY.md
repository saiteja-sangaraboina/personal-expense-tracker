# 🔒 Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security vulnerability in this project:
1. Please do not open a public GitHub issue.
2. Email security reports directly to `saitejasangaraboina@gmail.com`.
3. Include detailed steps to reproduce the vulnerability and potential impact.
4. You will receive a response within 48 hours with remediation details.
