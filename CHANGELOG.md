# 📝 Changelog

All notable changes to this project will be documented in this file.

## [1.2.0] - 2026-11-20
### Added
- Multi-currency exchange rate calculation utility and currency switcher.
- 30-day interactive daily expense heatmap visualizer.
- Printable PDF financial statement report generator.
- Real-time NotificationCenter for budget overages and upcoming bills.
- Unit test suites covering currency calculations and visual layout components.

## [1.1.0] - 2026-11-20
### Added
- Savings Goals module with visual progress bars and deposit actions.
- Subscriptions and recurring bills management with monthly total calculations.
- Bulk CSV bank statement parser and drag-and-drop import modal.
- Automated test suites using Jest and Vitest.

## [1.0.0] - 2026-11-20
### Added
- Initial full-stack release with MERN stack.
- JWT authentication, password hashing with bcrypt, and user-level data isolation.
- Income and expense transactions CRUD with pagination, filtering, and CSV export.
- Interactive dashboard with KPI summary cards, area charts, and category pie charts.
