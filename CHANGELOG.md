# 📝 Changelog

All notable changes to this project will be documented in this file.

## [1.6.0] - 2026-11-21
### Added
- Bill Splitter utility and interactive modal with equal, tip, tax calculations, and clipboard sharing.
- Spotify-Wrapped style Year in Review annual financial recap modal with peak spending month and top categories.
- Bill Reminder Engine with urgency classification (overdue, due today, due soon) and deadline alerts card.
- Compound Interest & Investment Portfolio growth simulator with time-to-target forecasting in Goals.
- Monthly Budget Health & Envelope Utilization matrix with capacity indicators and risk categorization.
- Expanded Vitest unit tests to 27 test files (88 passing unit tests).

## [1.5.0] - 2026-11-20
### Added
- Multi-Wallet & Account Portfolio manager with inter-account balance transfer modal.
- Net Worth & Liquidity Runway calculator with debt-to-asset solvency metrics.
- Debt Payoff simulator supporting Avalanche and Snowball elimination strategies.
- Federal progressive tax bracket & self-employment tax estimator.
- FIRE (Financial Independence, Retire Early) milestone projection engine.
- Browser-compatible XML multi-sheet Excel spreadsheet export engine.
- Session inactivity monitoring with automated logout warning modal.
- Custom hashtag taxonomy parser and multi-tag transaction badge filter.
- Client-side 4-digit Security PIN pad with SHA-256 attempt throttling.
- Emergency Fund essential expense baseline analyzer and safety reserve gauge.

## [1.4.0] - 2026-11-20
### Added
- Smart AI Spending Insights engine with natural language category shift analysis.
- 50/30/20 rule budgeting calculator and automated buffer limit suggestions.
- OCR camera receipt scanner modal with automatic vendor detection and itemization.
- Personalized time-aware WelcomeBanner on Dashboard with financial pulse indicators.
- QuickActionBar speed-dial and MobileNav bottom navigation bar.
- Structured request latency telemetry and client audit logging middleware.
- Expanded Vitest and Jest testing coverage to 19 suites (63 passing tests).
- Detailed Testing Architecture & Verification Guide (`TESTING_GUIDE.md`).

## [1.3.0] - 2026-11-20
### Added
- 100-point Financial Health Score calculator with metric breakdown.
- Linear regression 30-day spending projection and forecasting engine.
- Gamified savings milestone badges and achievement unlocks.
- Global keyboard navigation shortcuts (`N` for new transaction, `T` for theme, `?` for help).

## [1.2.0] - 2026-11-20
### Added
- Multi-currency exchange rate calculation utility and currency switcher.
- 30-day interactive daily expense heatmap visualizer.
- Printable PDF financial statement report generator.
- Real-time NotificationCenter for budget overages and upcoming bills.
- Unit test suites covering currency calculations and visual layout components.

## [1.1.0] - 2026-11-20
### Added
- Savings Goals module with visual progress bars and deposit actions.
- Subscriptions and recurring bills management with monthly total calculations.
- Bulk CSV bank statement parser and drag-and-drop import modal.
- Automated test suites using Jest and Vitest.

## [1.0.0] - 2026-11-20
### Added
- Initial full-stack release with MERN stack.
- JWT authentication, password hashing with bcrypt, and user-level data isolation.
- Income and expense transactions CRUD with pagination, filtering, and CSV export.
- Interactive dashboard with KPI summary cards, area charts, and category pie charts.
